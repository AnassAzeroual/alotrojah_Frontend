## §ENV — environment faults and exact recoveries
- Stale/wedged `ng serve` (mixed old/new chunks, dual ng-c scopes, phantom template errors): kill ONLY the PID that owns the dev port — `netstat -ano | findstr :4200` → `taskkill /F /PID <pid>` → rerun. Same for a wedged `php artisan serve` (`:8000`). **Never blanket `taskkill /F /IM node.exe`** — it kills the user's own node processes (editors, their stacks, other agents); if the port owner may be the user's server, STOP and ask before killing anything.
- `ng serve` binds IPv6 only (`[::1]:4200`) — probe with `localhost`/`[::1]`; `127.0.0.1` refuses. `php artisan serve` silently moves to the NEXT free port when the requested one is taken — trust `netstat -ano`, never the banner.
- Playwright `webServer.reuseExistingServer: true` — a reused `:8000` artisan serves the DB it BOOTTED with, so a leftover verify/dev server silently feeds wrong data (once wrote e2e rows into dev; the e2e runner carries the same warning in its header, and the menu guards the port before every run).
- Never `prettier --write` a file that is already committed-dirty — the whole-file reflow buries the review diff; hand-match its style on the added lines only (a prior `shell.component.html` pass did exactly that). HEAD-cleanliness must be tested on a temp copy INSIDE the repo.
- Angular 22: `allowSignalWrites` is deprecated — signal writes from effects are always allowed now.
- Shared git workspace: every commit carries the USER's git identity (agents never commit, R1) and the index can hold another agent's staged files — never `reset`/`checkout`/`commit` blindly here.
- `npm run typecheck` ≠ AOT check. `ng serve`/`ng build` flag template errors tsc passes (`labels.length` on optional, `new` in bindings — bindings forbid `new`, use a method).
- Vitest: jsdom Chart.js needs a synchronous explicit fake (`importOriginal` → TDZ error); `ng test` only.
- Prettier: `public/i18n/*.json` are CRLF and OUTSIDE the gate glob — don't mass-"fix" them. Match file style on added lines only.
- Playwright: `fill()` fires `input`, not `(change)` → `.blur()`/Enter or bind `(input)`; open `app-dropdown` lists clip pointer events (click a real option, trigger/backdrop clicks fail); `toContainText('20')` matches `/ 20` (assert `'20/ 20'` or await PATCH; bare `reload()` cancels in-flight PATCHes); select rows by content (Arabic sort puts الفرقان before النور); option `value` types must match with `===` (stringified numeric ids never match); center lists lead with a placeholder (never `.first()`); `getByTestId` for static controls, content selection for dynamic values, `exact:true` on shared labels.
- E2e counts on shared DBs are floors (`expect.poll ≥ N`), never exact. Failed runs leave orphans that break hand-math tests — clean them.
- HttpTestingController: `expectOne` fails on refires → `match` + flush-all.
- Angular resources: params compare by OBJECT IDENTITY (new object re-fires + cancels); never `inject()` in loaders (NG0203); dependent null-resolving resources need the parent's `isLoading()` in the UI gate.
- HttpClient uses fetch, not XHR (page-side XHR interception sees nothing — use CDP Network).
- Dev-server Lighthouse numbers are meaningless (unminified); npm `RemoteException` stderr noise is harmless; `.angular` cache lies (clean it).
- Working tree is LF (`core.autocrlf=true` normalizes on commit); some editors write CRLF back and prettier's endOfLine gate flags those files. Fix with `tr -d '\r' < f > f.lftmp && mv f.lftmp f`; never `--write` a committed-dirty file (see above).
- Zoneless CD timing: a `setTimeout(0)` can run BEFORE Angular applies a class change — `focus()` on a still-`visibility:hidden` node silently no-ops (drawer open path). Gate focus behind a rAF loop checking `getComputedStyle(el).visibility === 'visible'`.
